## Local preview

Open `index.html` in a browser, or:

```bash
npx serve .
```

## Publish on GitHub Pages

1. On GitHub (logged in as **musadiqmehmood**), create a **public** repository named exactly **`musadiqmehmood.github.io`**.
2. Push this folder to `main`:

```bash
git remote add github https://github.com/musadiqmehmood/musadiqmehmood.github.io.git
git branch -M main
git push -u github main
```

3. Repo **Settings → Pages → Source: Deploy from a branch → `main` / `/ (root)` → Save**.

Site URL after a minute or two: [https://musadiqmehmood.github.io/](https://musadiqmehmood.github.io/)
